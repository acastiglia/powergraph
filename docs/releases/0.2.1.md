# PowerGraph 0.2.1

Renames the Aggregations setting to Statistics.

## Changes
- The **Aggregations** setting is now called **Statistics**. It still picks which of max, average and, for power, normalized power show beside the current value on larger fields.
- After upgrading from 0.2.0, each field's statistics reset to the default, max only. Re-select any others in Power Graph's settings.
