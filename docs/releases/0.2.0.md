# PowerGraph 0.2.0

Adds settings, two new data fields, and ride statistics alongside the current value.

## What's new
- Cadence and speed graph data fields. Speed is shown in km/h or mph, following the units set in the Karoo user preferences.
- A settings screen, opened from Power Graph in the Karoo's app drawer, with settings for each data field:
  - **Smoothing** (power and cadence): average the current value over 1, 3, 10 or 30 seconds. The graph still plots every reading.
  - **Aggregations**: show your ride's max, average and, for power, normalized power beside the current value on larger fields. Pick any combination; they stack in the same order every time.
  - **Zone colors** (power and heart rate): color the bars by training zone, or turn it off for plain gray bars.
- Settings changes apply right away to fields already on screen.
- Heart rate can now show the ride max, like power.

## Improvements
- The current value's text scales up on taller full-size fields.
- Zero readings show as a thin bar, so the bottom of the graph stays visible.
